# Instructions

### Please read the following instructions carefully before proceeding with the task.

1. Creare a new git branch with a name of you choice. 
2. Now create a new .md file in the root directory of your project.
3. Write a short note on what we learnt in our last class
4. Stage and commit the changes to your new branch.
5. Push the branch to the remote repository after you have cloned the repository to your local machine.
6. Go to github.com and create a pull request for your new branch so that it can be reviewed and merged into the main branch.
7. See you in class for review and discussion of your pull request.
